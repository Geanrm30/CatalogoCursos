Catálogo de Cursos – Mini App (C# Consola)

Generado con ayuda de GitHub Copilot y revisado manualmente.

Descripción

Esta mini aplicación de consola permite listar cursos, buscar por nombre y ver una paginación simulada.
Forma parte del caso práctico “Coordinación de tareas: asignación, seguimiento y plazos”, utilizando herramientas digitales (Trello y GitHub) para gestionar el desarrollo colaborativo.

Requisitos

Tener instalado .NET SDK 6.0 o superior
(verificar con dotnet --version)

Sistema operativo Windows, macOS o Linux.

Instrucciones de ejecución

Abrir una terminal o consola.

Crear el proyecto (si no existe):

dotnet new console -n CatalogoCursos


Reemplazar el contenido del archivo Program.cs por el código del proyecto.

Ejecutar:

dotnet run


Usar el menú del programa:

1 → Listar todos los cursos

2 → Buscar curso por nombre

3 → Ver cursos con paginación simulada

4 → Salir del programa
